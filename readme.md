# Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains my solutions for Module 4, Assignment 1. The assignment
covers core TypeScript concepts from Modules 1, 2, and 3:

- Basic types and optional/default/rest parameters
- Union types and type narrowing with typeof
- Readonly tuples
- Interfaces
- Generics, including the keyof constraint
- Promises and async functions
- Object-Oriented Programming with protected and private access modifiers

All 8 coding problems are solved in a single file, solutions.ts, with explicit
parameter and return types and no use of any.
